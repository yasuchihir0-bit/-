# 東海中 受験トレーニング

東海中学校の入試対策として、**算数・理科・社会**（国語以外）の問題を練習できる Web アプリです。
インストール不要で、ブラウザで `index.html` を開くだけで使えます（スマホ・タブレット対応）。

## できること

| 教科 | 分野 | 出題のしかた |
| --- | --- | --- |
| 🔢 算数 | 計算・逆算／割合と比／速さ／特殊算／数の性質・場合の数／図形 | **毎回数字が変わる自動生成**（数字・小数・分数で入力） |
| 🔬 理科 | 生物／地学／物理／化学 | 4 択の知識問題 |
| 🔬 理科 | 計算問題（てこ・ばね・溶解度・中和・ふりこ・音・浮力・電流） | 自動生成 |
| 🗾 社会 | 地理／東海・中部地方／歴史／公民 | 4 択の知識問題 |

- **ミニ模試**：3 教科から 5 問ずつ、計 15 問。時間も計測します。
- **解説つき**：答えたらすぐに正解と解き方を表示。
- **まちがい復習**：まちがえた問題を自動でためて、あとから解き直せます（正解すると消えます）。
- **成績**：分野ごとの正答率と「いちばん苦手な分野」を表示。
- 記録はその端末のブラウザ（localStorage）にだけ保存されます。

算数の特殊算は、旅人算・通過算・流水算・時計算・植木算・つるかめ算・過不足算・年齢算・仕事算・ニュートン算・濃度・売買損益・数列・曜日の計算などをカバーしています。
社会には、愛知県・東海地方（中京工業地帯、輪中、木曽三川、渥美半島、桶狭間・長篠の戦い など）の問題も入れています。

## 使い方

```bash
# そのまま開く
open index.html

# または簡易サーバーで（スマホから同じ Wi-Fi で開くときなど）
python3 -m http.server 8000
```

GitHub Pages で公開すれば、URL を開くだけでどこでも使えます（Settings → Pages → ブランチを選択）。

## 問題を追加するには

- 理科：`js/data/science.js` の `bank` に `{ cat, q, c: [正解, ちがう選択肢…], exp }` を追加
- 社会：`js/data/social.js` の `bank` に同じ形で追加
- 算数・計算問題：`js/data/math.js` などに「問題を返す関数」を書き、分野の `gens` に追加

```bash
node tests/check.js   # 自動生成の問題を大量に作って、答えや表示がおかしくないか確認
```

## ファイル構成

```
index.html            画面
css/style.css         見た目（ダークモード対応）
js/util.js            分数計算・入力の解釈など
js/data/math.js       算数（自動生成）
js/data/science.js    理科（知識問題＋計算問題）
js/data/social.js     社会（知識問題）
js/app.js             画面の動き・成績の保存
tests/check.js        問題生成のチェック
```
