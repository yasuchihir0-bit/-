# 東海中 理科トレーニング

東海中学校の入試対策用に、**理科（生物・地学・物理・化学）** を練習できる Web アプリです。
インストールは不要で、ブラウザで `index.html` を開くだけで使えます（スマホ・タブレット対応）。

使い方・画面・復習のしくみは「東海中 国語トレーニング」と同じです。出題範囲を理科にかえ、**数字で答える計算問題**を加えました。

## 東海中の傾向に合わせた工夫

東海中の理科は、**生物・地学・物理・化学から 1 題ずつの大問 4 題**が中心で、**実験・観察をもとにした問題と計算問題が多い**と言われています。
そこで、このアプリでは次のようにしています。

- **計算問題を自動で作って出題**（数字がそのつど変わるので、何回でも練習できる）
  - てこ（棒の重さ・2 つのおもり・ばねばかりで支える）、ばね（直列・並列・自然の長さ）、滑車・輪軸、浮力、ふりこ
  - 回路の電流、電熱線の発熱、音の速さ（こだま・水中・動く船）
  - 溶解度（結晶の量・ほう和水よう液）、食塩水のこさ（混ぜる・うすめる）
  - 中和（ちょうど中和・あと何 cm³・こさを変える）、気体の発生量（反応する量の限界）、金属の酸化（4 : 1・3 : 2・反応しなかった銅）
  - 南中高度・経度と南中時刻・星の動き、湿度と露点、地震（P 波・S 波・初期微動継続時間）、蒸散、心臓の拍動、けんび鏡
- 知識問題も、**実験の手順や「なぜそうなるか」を問う問題**を多めにしています（ふ入りの葉、だ液の実験、ガスバーナー、けんび鏡 など）
- **すべて選ぶ** 問題と、用語を **書く** 問題（記述）もあります
- すべての問題に **難易度（★★標準・★★★発展＝東海中レベル）** をつけ、しぼりこんで練習できます
- ホームの **「力だめし」→「東海中レベル」** は ★★★ 中心の 15 問で、計算が多い分野（力・電気・とけ方・水よう液・気体・天体）を多めに出します

※ 傾向は塾などの公開情報をもとにした目安です。最新の出題は過去問で確認してください。

## 答え方

| 形式 | 答え方 |
| --- | --- |
| 選択 | 4 つから 1 つえらぶ（キーボードは 1〜4） |
| すべて選ぶ | あてはまるものをすべてえらんでから「答える」 |
| 記述 | 用語を書く。**ひらがなで OK**（漢字でも正解） |
| 計算 | 数字で答える。**単位はいりません**（つけても OK）。小数（0.25）でも分数（1/4）でも正解になります |

## 使い方（毎日のやり方）

1. ホームの **「▶ 今日の学習をはじめる」** を押す（10 問）。復習の問題が先に出て、足りない分は新しい問題になります。
2. 1 日の目標（はじめは 20 問）になるまで、結果画面の「▶ 続けて 10 問」を押す。
3. 時間があれば **「📚 分野をえらぶ」** で、にがてな分野をクイズや暗記カードで練習する。
4. 週に 1 回くらい **「🏆 力だめし」**（ふつうのテスト／東海中レベル）をして、右上の **📊** で成長を確かめる。

はじめて開くと、3 枚の案内が出ます。右上の **❓** でいつでも使い方を見られます（1 日の目標もここで変えられます）。

## 機能

### 画面
| 画面 | できること |
| --- | --- |
| ホーム | 今日の目標までの進み具合・連続日数・「今日の学習」ボタン・全体の覚えぐあい |
| 📚 分野をえらぶ | 分野ごとに **クイズ（10 問）** と **暗記カード（20 枚）** を切りかえ。むずかしさも選べる |
| 🏆 力だめし | 15 問のテスト。「東海中レベル」は ★★〜★★★ だけ（計算・記述あり） |
| 📊 学習の記録 | グラフでの分析（下記） |
| ❓ 使い方 | 使い方・マークの意味・1 日の目標の設定 |

### 覚えぐあい（4 段階）
問題ごとに記録し、色の濃さで表示します。

- **覚えた**：2 週間以上あけても正解できた
- **もう少し**：数日あけて正解できた
- **にがて**：まちがえた
- **まだ**：まだ解いていない

計算問題は数字が毎回変わるので、分野ごとに決まった数（計算の種類 × 3 問）を 1 分野ぶんとして数えます。

### 復習のしくみ（間隔反復）
- 正解するたびに、次に出るまでの間をのばします（当日 → 1 日 → 3 日 → 1 週間 → 2 週間 → 1 か月）。まちがえると最初にもどります。
- 初めてで正解した問題は「知っている問題」として 3 日後に確認します。
- まちがえた計算問題は、同じ数字のままもう一度出ます。
- 暗記カードは、答えを思い出してからめくり「× 思い出せない／△ あやしい／○ 思い出せた」を自分でつけます（キーボードはスペースでめくる、1・2・3 で評価）。

### 学習の記録（📊）
- 連続日数・学習した日・解いた数・正答率・学習時間・覚えた問題の割合
- 学習カレンダー（直近 16 週）、直近 14 日の問題数、正答率の推移（表でも見られる）
- 分野ごとの覚えぐあいと正答率、むずかしさ別の正答率
- よくまちがえる問題 TOP10（そのまま練習できる）と「次にやるとよいこと」
- 記録の書き出し・読みこみ（別の端末へ移す・バックアップ）

記録はその端末のブラウザ（localStorage）にだけ保存されます（国語版とは別に保存されます）。

## 開き方

```bash
open index.html                 # そのまま開く
python3 -m http.server 8000     # 同じ Wi-Fi のスマホから開くとき
```

GitHub Pages で公開すれば、URL を開くだけでどこからでも使えます（Settings → Pages）。

## 問題を追加するには

`js/data/seibutsu.js`（生物）・`chigaku.js`（地学）・`butsuri.js`（物理）・`kagaku.js`（化学・実験器具）に、次の形で 1 行追加します。

```js
// 選択式（c の先頭が正解。選択肢は自動でシャッフルされます）
{ cat: 'shokubutsu', lv: 2, q: '問題文', c: ['正解', 'ちがう選択肢', 'ちがう選択肢', 'ちがう選択肢'], exp: '解説' },
// 記述式（a に正解として認める答えを並べる。ひらがな・カタカナのちがいは自動で無視）
{ cat: 'kitai', lv: 3, q: '問題文', a: ['酸化', 'さんか'], exp: '解説' },
// すべて選ぶ（ok に正解をすべて）
{ cat: 'dobutsu', lv: 3, q: '問題文', c: ['A', 'B', 'C', 'D'], ok: ['A', 'C'], exp: '解説' },
// 数値で答える（n が正解、unit が単位）
{ cat: 'kigu', lv: 2, q: '問題文', n: 400, unit: '倍', exp: '解説' },
```

`lv` は難易度（2＝標準、3＝発展）。分野の id は `js/data/rika.js` にあります。
計算問題の自動生成は `js/data/calc.js` にあり、`gen('名前', [[難易度, 問題を作る関数], ...])` の形で追加できます。

```bash
node tests/check.js   # 選択肢の重複・正解の有無・問題の重複・計算問題の答えが割り切れるかなどをチェック
```
