# 東海中 国語・社会・理科トレーニング

> **このアプリは東海中学校の公式のものではありません。** 学校とは関係のない、受験勉強用の非公式アプリです。
> 出題の傾向やむずかしさは公開情報をもとにした目安で、問題文・例文・解説はすべてこのアプリのために作成したものです。
> 内容の正確さには注意していますが、辞書や教材、統計資料でも確認してください。学習記録は端末のブラウザ内にだけ保存され、外部には送信しません。

東海中学校の入試対策用に、次の 3 つの教科を練習できる Web アプリです。
インストールは不要で、ブラウザでページを開くだけで使えます（スマホ・タブレット対応）。

| ページ | 教科 | 内容 |
| --- | --- | --- |
| `kokugo.html` | 📖 国語 | 長文読解（説明文・物語文）と、記述・言葉の意味・ことわざ・慣用句などの知識（漢字は除く） |
| `shakai.html` | 🗾 社会 | 地理・歴史・公民・時事（東海地方・年代の並べかえをふくむ） |
| `rika.html` | 🔬 理科 | 生物・地学・物理・化学・実験（635 問・知識問題） |

3 つのページは同じしくみ（今日の学習・分野別のクイズと暗記カード・力だめし・間隔反復による復習・学習の記録）で動きます。
学習の記録は教科ごとに別々に保存されます。それぞれのホームの下にある「ほかの教科」から行き来できます。

# 🗾 社会トレーニング（shakai.html）

## 東海中の傾向に合わせた工夫（社会）

塾などの分析では、東海中の社会は **地理と歴史が中心で、公民（政治）の出題は少なめ**、歴史は **近現代と通史** の比重が高く、**都道府県ごとの産業・名産** や **用語を漢字で書く問題**、理由を説明する記述が多いとされています。時事問題は地理・歴史の問題の中に組みこまれて出ることが多いようです。
そこで、このアプリでは次のようにしています。

- **地理・歴史を厚く、公民は少なめ**（地理 約 440 問・歴史 約 390 問・公民 約 145 問・時事 約 50 問）
- 「**東海地方**」（122 問）：中京工業地帯・輪中と木曽三川・宝暦治水・用水（愛知・豊川・明治）・伝統工芸・旧国名・宿場や城・戦国〜江戸の歴史・濃尾地震や伊勢湾台風・南海トラフ など
- 「**日本の各地方**」（90 問）：都道府県ごとの農産物・伝統的工芸品・県庁所在地・地形
- 歴史は **近代（110 問）** を最も多くし、「古い順に並べたもの」「組み合わせとして誤っているもの」などの **通史の問題** も入れています
- 「**年代の並べかえ**」：112 のできごと（奴国の金印〜令和）から 4 つを組み合わせて自動で出題
- 「**時事問題（2025〜2026 年）**」（49 問）：2026 年 2 月の衆議院議員総選挙、初の女性首相、飛鳥・藤原の宮都の世界遺産登録、南鳥島沖のレアアース泥、柏崎刈羽原発の再稼働、愛知・名古屋アジア競技大会、出生数と出生率、最低賃金、三陸沖の地震と後発地震注意情報、憲法公布 80 年、アメリカ建国 250 年、ノーベル賞 など

※ 傾向は塾などの公開情報をもとにした目安です。最新の出題は過去問で確認してください。
※ 時事問題は 2026 年 11 月までの報道をもとに作っています。数字（議席・メダル・統計など）は報道の値なので、入試の前に時事問題集などでも確かめてください。

# 📖 国語トレーニング（kokugo.html）

## 東海中の傾向に合わせた工夫

東海中の国語は、**説明文と物語文の読解 2 題が中心**で、**記述・書きぬきの設問が多く、選択式は少なめ**と言われています。
語句・文法などの知識問題は全体の 1〜2 割ほどで、**文章の中に組みこまれて出ることが多い**とされます。
そこで、このアプリでは次のようにしています。

- **読解に直結する語彙**を重点的に練習できる分野を用意
  - 「気持ちを表す言葉」（物語文：やるせない・後ろめたい・屈託がない・場面から心情を選ぶ問題 など）
  - 「説明文によく出る言葉」（普遍的・相対的・抽象的・逆説・恣意的・部分否定 など）
  - 「言葉の使い方・誤用」（すべからく・流れにさおさす・敷居が高い・汚名返上 など）
- **📖 長文読解**：オリジナルの説明文 3 本・物語文 3 本（各 800〜1000 字）に、東海中レベルの設問を 7 問ずつ（全 42 問）
  - 理由・心情・言いかえ・接続語・抜き出し（字数指定）・内容合致（すべて選ぶ）・表現の特ちょう
  - 選択肢は「本文にあるが理由になっていない」「言い過ぎ」「逆」など、まぎらわしいものにしています
  - 60〜80 字の**記述は自己採点**：解答例と採点のポイントを見て ○・△・× をつけます
  - 本文は問題の上にいつも表示（たたむこともできます）。同じ文章の設問は本文の順に出ます
  - 長い文章を読むので「今日の学習」「力だめし」には入れず、ホームの「長文読解」から解きます
- **記述・読解の解き方**（42 問・うち ★★★ 32 問）：短い文章を読んで実際に解く発展問題（`js/data/kokugo6.js`）
  - 4 つの答案から「いちばんよい答案」を選ぶ（まちがいは「要素が足りない」「具体例のまま」「本文にない」「文末が合わない」など）
  - 答案の直すべき点・入れるべき内容を「すべて選ぶ」、40〜60 字の記述（自己採点）
- 慣用句は、**例文の中で意味を問う**形式を中心にしています
- **記述式**（（　）に入る言葉をひらがなで書く）の問題もあります
- すべての問題に **難易度（★基礎・★★標準・★★★発展＝東海中レベル）** をつけ、しぼりこんで練習できます
- ホームの **「東海レベル実戦」** は、★★〜★★★の問題だけで 15 問（読解に関わる分野を多めに）出題します

※ 傾向は塾などの公開情報をもとにした目安です。最新の出題は過去問で確認してください。

## 使い方（毎日のやり方）

1. ホームの **「▶ 今日の学習をはじめる」** を押す（10 問）。復習の問題が先に出て、足りない分は新しい問題になります。
2. 1 日の目標（はじめは 20 問）になるまで、結果画面の「▶ 続けて 10 問」を押す。
3. 時間があれば **「📚 分野をえらぶ」** で、にがてな分野をクイズや暗記カードで練習する。
4. 週に 1 回くらい **「🏆 力だめし」**（ふつうのテスト／東海中レベル）をして、右上の **📊** で成長を確かめる。

はじめて開くと、3 枚の案内が出ます。右上の **❓** でいつでも使い方を見られます（1 日の目標もここで変えられます）。

### 覚えぐあい（4 段階）
問題ごとに記録し、色の濃さで表示します。

- **覚えた**：2 週間以上あけても正解できた
- **もう少し**：数日あけて正解できた
- **にがて**：まちがえた
- **まだ**：まだ解いていない

### 復習のしくみ（間隔反復）
- 正解するたびに、次に出るまでの間をのばします（当日 → 1 日 → 3 日 → 1 週間 → 2 週間 → 1 か月）。まちがえると最初にもどります。
- 初めてで正解した問題は「知っている問題」として 3 日後に確認します。
- 暗記カードは、答えを思い出してからめくり「× 思い出せない／△ あやしい／○ 思い出せた」を自分でつけます（キーボードはスペースでめくる、1・2・3 で評価）。

### 学習の記録（📊）
- 連続日数・学習した日・解いた数・正答率・学習時間・覚えた問題の割合
- 学習カレンダー（直近 16 週）、直近 14 日の問題数、正答率の推移（表でも見られる）
- 分野ごとの覚えぐあいと正答率、むずかしさ別の正答率
- よくまちがえる問題 TOP10（そのまま練習できる）と「次にやるとよいこと」
- 記録の書き出し・読みこみ（別の端末へ移す・バックアップ）

記録はその端末のブラウザ（localStorage）にだけ保存されます。

## 問題を追加するには

`js/data/kokugo2.js` の `add` に、次の形で 1 行追加します。

```js
// 選択式（c の先頭が正解。選択肢は自動でシャッフルされます）
{ cat: 'kotowaza', lv: 2, q: '問題文', c: ['正解', 'ちがう選択肢', 'ちがう選択肢', 'ちがう選択肢'], exp: '解説' },
// 記述式（a に正解として認める答えを並べる。ひらがな・カタカナのちがいは自動で無視）
{ cat: 'kanyo', lv: 2, q: '問題文', a: ['はな', '鼻'], exp: '解説' },
```

`lv` は難易度（2＝★★標準、3＝★★★発展。★ は使いません）。対義語・類義語は `ANTONYMS` / `SYNONYMS` に `['言葉', '言葉', 難易度]` を足すだけで出題に加わります。

```bash
node tests/check.js   # 国語・社会・理科で、選択肢の重複・正解の有無・問題の重複などをチェック
```

## 👪 保護者画面

ホームのいちばん下の「👪 保護者の方へ」（または ❓ 使い方のページ）から開きます。教科ごとに、次のことがわかります。

- **まちがえた問題と、そのとき答えた内容**（えらんだ選択肢・入力した答え・「わからない」・記述で書いた文章）
- 記述（自己採点）の答えは、お子さんが書いた文章と ○△×
- 同じ問題を何回まちがえたか、その後の復習で正解できたか、解説
- 期間（今日・7 日間・30 日間・すべて）と分野でのしぼりこみ、期間内の解いた数・正答率

記録は新しい 3000 件まで、その端末のブラウザに保存されます（「記録を書き出す」には、手書きの画像以外がふくまれます）。

### 保護者の端末で見る（Google 経由・お子さんのログインなし）

お子さんの端末でまちがえた問題と答えた内容を、**お子さんがログインしなくても**、保護者の端末のアプリの保護者画面で見られます。
提供する人がアプリを 1 か所（https:// の置き場所）に置き（[`docs/DEPLOY.md`](docs/DEPLOY.md)）、各家庭は保護者画面の**案内つきの手順**で、保護者の Google アカウントに「受け口」（`tools/apps-script/Code.gs`）を作ります。お子さんの端末は、保護者の端末が作る**設定リンク（QR コード）**を開くだけです。
**家庭の設定のしかたは [`tools/apps-script/SETUP.md`](tools/apps-script/SETUP.md)** を見てください（最初に 1 回だけ、10 分ほど）。
仕様と、ほかの人も使えるようにするための方針は [`docs/SPEC.md`](docs/SPEC.md) にあります（受け口は家庭ごと。運営は記録を預かりません）。

- 送受信のプログラムは `js/sheetsync.js`、受け口は `tools/apps-script/Code.gs` です。
- 書くときも読むときも合言葉が必要です。まちがいは、保護者のスプレッドシート（「まちがい」「学習量」シート）にもたまります。
- テスト：`node tests/apps-script.js`（受け口を、Google の部品を模擬して動かします）。

### 保護者の端末から見る（claude.ai のログインで同期）

claude.ai の公開ページで開いたときは、まちがいの記録が claude.ai 側にも保存され、別の端末から見られます（`js/sync.js`）。

1. お子さんの端末と保護者の端末で、**同じ claude.ai アカウントにログイン**して公開ページを開く。
2. お子さんが問題を解くと、結果の画面が出たとき（と、教科えらびの画面を開いたとき）に記録が送られる。
3. 保護者の端末で教科を開き、「👪 保護者の方へ」→「ほかの端末の記録」を見る。「🔄 記録を更新する」で最新になる。

- 保存先は、ログイン中のアカウントだけが読める場所（`data/users/<自分の id>/`）です。リンクを知っているほかの人からは見えません。
- 同期するのは、教科・端末ごとに新しい 600 件（手書きの画像は 40 件）と、直近 90 日の学習量です。
- パソコンでファイルを直接開いたとき（VS Code の Live Server など）は同期しません。

## VS Code で編集する

1. [VS Code](https://code.visualstudio.com/) をインストールします。
2. ZIP を展開し、VS Code の「ファイル → フォルダーを開く」で、展開したフォルダーを開きます。
3. 右下に「おすすめの拡張機能」が出たら **Live Server** を入れます（`.vscode/extensions.json` で指定済み）。
4. `index.html` を右クリック →「Open with Live Server」。保存するたびにブラウザが自動で更新されます。
   （Live Server なしでも、`index.html` をダブルクリックすれば開けます）

### 問題の書き方（社会・理科）

```js
// 選択式：c の先頭が正解（出題時にシャッフル）
{ cat: 'tokai', lv: 2, q: '問題文', c: ['正解', 'ちがう', 'ちがう', 'ちがう'], exp: '解説' },
// 記述式：a に正解として認める答え（ひらがな・カタカナのちがいは自動で無視）
{ cat: 'kodai', lv: 3, q: '問題文', a: ['卑弥呼'], exp: '解説' },
// すべて選ぶ：ok に正解（複数可）。問題文は「すべて選びなさい。」で終える
{ cat: 'seiji', lv: 3, q: '〜をすべて選びなさい。', c: ['ア', 'イ', 'ウ', 'エ'], ok: ['ア', 'ウ'], exp: '解説' },
```

`cat` は各教科の分野一覧（`shakai.js` / `rika.js` の `cats`）にある id を使います。
ファイルによっては `C(分野, 難易度, 問題, [正解, …], 解説)` のような短い書き方をしています（ファイルの先頭に説明があります）。

```bash
node tests/check.js   # Node.js が必要。最後に all ok と出れば OK
```

## 漢字で書く問題について

「✍️ 漢字で書く」（手書きで答える練習）と、クイズで答えを手書きにする「書き取り」は、なくしました。
国語の「漢字の書き取り」の問題（48 問）も外してあります。
以前の版は git の履歴に残っています（`git log --grep 書き取り` で、手書きを入れたコミットがわかります）。手書きの機能そのものは `js/app.js` に残してあり、
データ側で `app.kanji = true` を設定し、`kanjiExtra`（`[分野, ヒント, 漢字, よみ]`）を用意すれば、また使えます。
