# 東海中 国語トレーニング

東海中学校の入試対策用に、**国語のうち「漢字」と「文章題（読解）」以外**の分野を練習できる Web アプリです。
インストールは不要で、ブラウザで `index.html` を開くだけで使えます（スマホ・タブレット対応）。

## 東海中の傾向に合わせた工夫

東海中の国語は、**説明文と物語文の読解 2 題が中心**で、**記述・書きぬきの設問が多く、選択式は少なめ**と言われています。
語句・文法などの知識問題は全体の 1〜2 割ほどで、**文章の中に組みこまれて出ることが多い**とされます。
そこで、このアプリでは次のようにしています。

- **読解に直結する語彙**を重点的に練習できる分野を用意
  - 「気持ちを表す言葉」（物語文：やるせない・後ろめたい・屈託がない・場面から心情を選ぶ問題 など）
  - 「説明文によく出る言葉」（普遍的・相対的・抽象的・逆説・恣意的・部分否定 など）
  - 「言葉の使い方・誤用」（すべからく・流れにさおさす・敷居が高い・汚名返上 など）
- 慣用句は、**例文の中で意味を問う**形式を中心にしています
- **記述式**（（　）に入る言葉をひらがなで書く）の問題もあります
- すべての問題に **難易度（★基礎・★★標準・★★★発展＝東海中レベル）** をつけ、しぼりこんで練習できます
- ホームの **「東海レベル実戦」** は、★★〜★★★の問題だけで 15 問（読解に関わる分野を多めに）出題します

※ 傾向は塾などの公開情報をもとにした目安です。最新の出題は過去問で確認してください。

### むずかしさ

| 記号 | 目安 | 問題数 |
| --- | --- | --- |
| ★★ | 標準（中学入試でよく出るレベル） | 246 |

★★★ は、**言葉そのもの（知識）が難関校レベル**のものと、**問題の形式がむずかしい**ものです。

- 難関校レベルの知識の例
  - ことわざ・故事成語：蟷螂の斧・窮鼠猫をかむ・百年河清を待つ・いずれあやめかかきつばた・出藍の誉れ・隗より始めよ・烏合の衆・刎頸の交わり・朝三暮四・刻舟求剣 など
  - 慣用句：手をこまねく・鼻を明かす・眉につばをつける・歯牙にもかけない・臍をかむ・満を持す・堂に入る など
  - 四字熟語：巧言令色・当意即妙・是々非々・虚心坦懐・竜頭蛇尾・二律背反・八面六臂 など
  - 物語文の言葉：わだかまり・しがらみ・ほだされる・ないまぜ・狼狽・焦燥・悔恨・畏怖・おずおず・ぶしつけ・おもねる・たしなめる など
  - 説明文の言葉：概して・形骸化・矮小化・顕在化・享受・示唆・齟齬・乖離・陳腐・功罪・通念・趨勢・葛藤・メタファー・アイロニー など
  - 文学史：『銀の匙』『路傍の石』『二十四の瞳』『智恵子抄』『春と修羅』『若菜集』、西鶴・近松・馬琴・十返舎一九、世阿弥 など
- 形式がむずかしい問題の例

  - まちがいの選択肢が紛らわしい（気持ちの言葉が全部ネガティブ、似た意味のことわざが並ぶ など）
  - 文法の識別（「の」「ない」「られる」「だ」「に」「と」「ばかり」「さえ」）、文節・単語の数え方
  - **すべて選ぶ** 問題（12 問）と、意味から思い出して **書く** 問題（記述 27 問）
  - 本来の意味と誤用の区別（憮然・潮時・御の字・世間ずれ・浮き足立つ・天地無用 など）

「今日の学習」で出す新しい問題は、半分を ★★★ にしています。「力だめし」の「東海中レベル」は ★★★ 中心の 15 問です。

★ の問題のデータは `js/data/kokugo.js` などに残してあり、`js/data/filter.js` を読みこまないようにすると、また出題されます。

## 使い方（毎日のやり方）

1. ホームの **「▶ 今日の学習をはじめる」** を押す（10 問）。復習の問題が先に出て、足りない分は新しい問題になります。
2. 1 日の目標（はじめは 20 問）になるまで、結果画面の「▶ 続けて 10 問」を押す。
3. 時間があれば **「📚 分野をえらぶ」** で、にがてな分野をクイズや暗記カードで練習する。
4. 週に 1 回くらい **「🏆 力だめし」**（ふつうのテスト／東海中レベル）をして、右上の **📊** で成長を確かめる。

はじめて開くと、3 枚の案内が出ます。右上の **❓** でいつでも使い方を見られます（1 日の目標もここで変えられます）。

## 機能

### 画面
| 画面 | できること |
| --- | --- |
| ホーム | 今日の目標までの進み具合・連続日数・「今日の学習」ボタン・全体の覚えぐあい |
| 📚 分野をえらぶ | 分野ごとに **クイズ（10 問）** と **暗記カード（20 枚）** を切りかえ。むずかしさも選べる |
| 🏆 力だめし | 15 問のテスト。「東海中レベル」は ★★〜★★★ だけ（記述式あり） |
| 📊 学習の記録 | グラフでの分析（下記） |
| ❓ 使い方 | 使い方・マークの意味・1 日の目標の設定 |

### 覚えぐあい（4 段階）
問題ごとに記録し、色の濃さで表示します。

- **覚えた**：2 週間以上あけても正解できた
- **もう少し**：数日あけて正解できた
- **にがて**：まちがえた
- **まだ**：まだ解いていない

### 復習のしくみ（間隔反復）
- 正解するたびに、次に出るまでの間をのばします（当日 → 1 日 → 3 日 → 1 週間 → 2 週間 → 1 か月）。まちがえると最初にもどります。
- 初めてで正解した問題は「知っている問題」として 3 日後に確認します。
- 暗記カードは、答えを思い出してからめくり「× 思い出せない／△ あやしい／○ 思い出せた」を自分でつけます（キーボードはスペースでめくる、1・2・3 で評価）。

### 学習の記録（📊）
- 連続日数・学習した日・解いた数・正答率・学習時間・覚えた問題の割合
- 学習カレンダー（直近 16 週）、直近 14 日の問題数、正答率の推移（表でも見られる）
- 分野ごとの覚えぐあいと正答率、むずかしさ別の正答率
- よくまちがえる問題 TOP10（そのまま練習できる）と「次にやるとよいこと」
- 記録の書き出し・読みこみ（別の端末へ移す・バックアップ）

記録はその端末のブラウザ（localStorage）にだけ保存されます。

## 開き方

```bash
open index.html                 # そのまま開く
python3 -m http.server 8000     # 同じ Wi-Fi のスマホから開くとき
```

GitHub Pages で公開すれば、URL を開くだけでどこからでも使えます（Settings → Pages）。

## 問題を追加するには

`js/data/kokugo2.js` の `add` に、次の形で 1 行追加します。

```js
// 選択式（c の先頭が正解。選択肢は自動でシャッフルされます）
{ cat: 'kotowaza', lv: 2, q: '問題文', c: ['正解', 'ちがう選択肢', 'ちがう選択肢', 'ちがう選択肢'], exp: '解説' },
// 記述式（a に正解として認める答えを並べる。ひらがな・カタカナのちがいは自動で無視）
{ cat: 'kanyo', lv: 2, q: '問題文', a: ['はな', '鼻'], exp: '解説' },
```

`lv` は難易度（1＝基礎、2＝標準、3＝発展）。対義語・類義語は `ANTONYMS` / `SYNONYMS` に `['言葉', '言葉', 難易度]` を足すだけで出題に加わります。

```bash
node tests/check.js   # 選択肢の重複・正解の有無・問題の重複などをチェック
```
