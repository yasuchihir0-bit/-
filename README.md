# 東海中 国語トレーニング

東海中学校の入試対策用に、**国語のうち「漢字」と「文章題（読解）」以外**の分野を練習できる Web アプリです。
インストールは不要で、ブラウザで `index.html` を開くだけで使えます（スマホ・タブレット対応）。

## 出題分野

| 分野 | 内容 | 問題数 |
| --- | --- | --- |
| ことわざ | 意味・似た意味／反対の意味・（　）に入る言葉 | 24 |
| 慣用句 | 体の部分を使った慣用句、よくある誤用（気が置けない・役不足 など） | 22 |
| 四字熟語 | 意味・□に入る漢数字 | 18 |
| 故事成語 | 矛盾・蛇足・漁夫の利・推敲・他山の石 など | 12 |
| 対義語・類義語 | 組み合わせから毎回自動で出題 | 自動 |
| 言葉の意味 | おもむろに・なおざり・にべもない、カタカナ語 など | 17 |
| 敬語 | 尊敬語・謙譲語・丁寧語、身内の言い方、まちがい探し | 13 |
| 文法 | 主語・述語・修飾、文節・単語、品詞、「の」「られる」「ない」「ようだ」の識別、呼応の副詞、接続語 | 22 |
| 熟語の組み立て | 熟語の構成、打ち消しの字（不・無・非・未） | 9 |
| 表現技法・俳句 | 擬人法・倒置法・体言止め・比喩、季語、切れ字、俳人 | 15 |

## 機能

- **分野ごとに 10 問**：ホームの分野ボタンをタップするとすぐに始まります。
- **ミニテスト**：全分野から 15 問。かかった時間も表示します。
- **分野を選んで練習**：分野を組み合わせて、5／10／20 問を選べます。
- **解説つき**：答えるとすぐに正解と解説を表示します。
- **まちがい復習**：まちがえた問題がたまり、あとで解き直せます（正解すると消えます）。
- **成績**：分野ごとの正答率と、いちばん苦手な分野を表示します。
- 記録はその端末のブラウザ（localStorage）にだけ保存されます。
- キーボードでは 1〜4 で選び、Enter で次の問題に進めます。

## 使い方

```bash
open index.html                 # そのまま開く
python3 -m http.server 8000     # 同じ Wi-Fi のスマホから開くとき
```

GitHub Pages で公開すれば、URL を開くだけでどこからでも使えます（Settings → Pages）。

## 問題を追加するには

`js/data/kokugo.js` の `bank` に、次の形で 1 行追加します（`c` の先頭が正解。選択肢は自動でシャッフルされます）。

```js
{ cat: 'kotowaza', q: '問題文', c: ['正解', 'ちがう選択肢', 'ちがう選択肢', 'ちがう選択肢'], exp: '解説' },
```

対義語・類義語は `ANTONYMS` / `SYNONYMS` に組を足すだけで出題に加わります。

```bash
node tests/check.js   # 選択肢の重複・正解の有無・問題の重複などをチェック
```
