# 保護者の端末で見る（Google 経由）の設定

お子さんの端末でまちがえた問題と答えた内容を、**お子さんがログインしなくても**、保護者の端末のアプリの「保護者画面」で見られるようにする設定です。
最初に 1 回だけ、保護者の方が設定します（目安 20〜30 分）。

## しくみ

```
お子さんの端末のアプリ ──(まちがえた記録)──▶ 保護者の Google の「受け口」 ◀──(読みこみ)── 保護者の端末のアプリ
```

- 「受け口」は、保護者の Google アカウントのスプレッドシートに作る小さなプログラム（`Code.gs`）です。記録はそのスプレッドシートの「まちがい」「学習量」シートにたまります（スプレッドシートからも見られます）。
- 書きこむときも読み出すときも**合言葉**が必要です。アドレスを知っているだけでは、記録は読めません。
- 合言葉は 2 つに分けられます（おすすめ）。**送る合言葉**はお子さんの端末に、**見る合言葉**は保護者の端末にだけ入れます。こうすると、お子さんの端末では、ほかの端末の記録を読めません。
- 全体の仕様と、ほかの人も使えるようにするための方針は、[`docs/SPEC.md`](../../docs/SPEC.md) にあります。
- お子さんの端末にも保護者の端末にも、アプリを **claude.ai の外**で開く必要があります（claude.ai の公開ページは、外への通信が禁止されているため、この機能が使えません）。

## 1. アプリを、claude.ai の外に置く

アプリのフォルダ（ZIP を展開したもの）を、無料の置き場所に置きます。たとえば Netlify の「Drop」のように、**フォルダをドラッグ＆ドロップするだけ**で公開できるサービスがあります（無料のアカウントが必要な場合があります）。

- 置けたら、`https://（サービスが決めた名前）/start.html` を開くと、国語・社会・理科の選択画面が出ます。
- この置き場所のアドレスを、**お子さんの端末と保護者の端末の両方**で使います。
- 記録は端末ごと・アドレスごとに別々に保存されます。claude.ai の公開ページで解いた記録は、引きつがれません。

## 2. 受け口を作る（保護者の Google アカウント）

1. Google ドライブで、新しい **Google スプレッドシート** を作ります。名前は、たとえば「東海中 まちがい記録」。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初から入っているプログラムを**すべて消し**、このフォルダの `Code.gs` の内容を**そのまま貼りつけ**ます。
4. いちばん上のほうにある 2 つの行に、**自分だけの合言葉**（英数字 12 文字以上。ほかで使っていないもの。2 つは**ちがうもの**）を入れます。
   ```js
   const SECRET = 'ここを合言葉に書きかえる';   // 送る合言葉（お子さんの端末に入れる）
   const READ_SECRET = '';                       // 見る合言葉（保護者の端末にだけ入れる）
   ```
   - `SECRET` は、必ず書きかえてください。書きかえないと、受け口は何も受け付けません。
   - `READ_SECRET` は、`''` の間に合言葉を入れます（例：`'my-read-secret-2026'`）。**入れておくことをおすすめします。** 空のままだと、`SECRET` だけで送るのも見るのもできるので、お子さんの端末でも、ほかの端末の記録が読めてしまいます。
5. 💾（保存）を押します。
6. 右上の **デプロイ → 新しいデプロイ** を押し、歯車から種類を **「ウェブアプリ」** にします。
   - **次のユーザーとして実行**：自分
   - **アクセスできるユーザー**：**全員**（お子さんの端末は Google にログインしていないので、「全員」にします。合言葉がないと、書くことも読むこともできません）
7. **デプロイ** を押します。初回は「アクセスを承認」の画面が出ます。自分のアカウントを選び、「このアプリは Google で確認されていません」と出たら、**詳細 → （プロジェクト名）に移動（安全でないページ）** で進みます（自分で貼りつけたプログラムなので、このとおりで大丈夫です）。
8. 出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec` で終わるもの）をコピーします。
   - ブラウザでそのアドレスを開いて「記録の受け口は、動いています。」と出れば、公開できています。

## 3. アプリに設定する（両方の端末で、1 回ずつ）

お子さんの端末と、保護者の端末の**両方**で、次のことをします（合言葉は、お子さんの端末には**送る合言葉**、保護者の端末には**見る合言葉**を入れます。`READ_SECRET` を空にしたときは、どちらにも同じ合言葉です）。

1. 置き場所のアプリを開き、見たい教科（国語・社会・理科）を開く。
2. 教科のホームのいちばん下の **「👪 保護者の方へ」** を押す。
3. 「📨 お子さんの端末と記録をやりとりする」の欄に、**受け口のアドレス**と**合言葉**を貼りつける。お子さんの端末では、**お子さんの呼び名**（例：たろう。空でもかまいません）も入れる。保護者画面で、お子さんごとに見分けられます。
4. **「保存してためす」** を押す。「つながりました。」と出れば成功です。お子さんの端末では「記録を送れます」、保護者の端末では「記録を見られます」と出ます。
4. 「つながりました。」と出れば成功です。

設定は、その端末で**1 回だけ**です（国語・社会・理科のどの教科で設定しても、3 教科すべてに使われます）。まちがいの記録は教科ごとにたまり、保護者画面も教科ごとに見ます。

## 見かた

- お子さんの端末：問題をまちがえると、数秒後に自動で送られます（通信できないときは、あとでまとめて送ります）。
- 保護者の端末：教科の「👪 保護者の方へ」を開くと、自動で最新の記録を読みこみます。「ほかの端末の記録」に、まちがえた問題と答えた内容が出ます。「🔄 記録を更新する」でも読みこめます。
- スプレッドシートの「まちがい」シートでも、同じ記録が見られます（日付・教科・問題・正解・答えた内容）。

## うまくいかないとき

| 画面の表示 | 原因と対処 |
| --- | --- |
| 合言葉がちがいます | `Code.gs` に書いた合言葉と、アプリに入れた合言葉が同じか確かめる。合言葉を書きかえたら、**デプロイを更新**する（デプロイ → デプロイを管理 → 編集 → 新バージョン） |
| 受け口（Code.gs）が古いようです | 最新の `Code.gs` に貼りかえて、デプロイを更新する（アプリは、受け口の版番号を見て、古いときは送受信を止めます） |
| 受け口の合言葉の設定がまちがっています | `SECRET` と `READ_SECRET` が、12 文字以上で、たがいにちがうものか確かめる |
| 受け口が受け付けませんでした | アドレスが `/exec` で終わっているか、「アクセスできるユーザー：全員」になっているかを確かめる |
| 返事は確認できませんでした | 送れてはいますが、このブラウザでは返事が読めません。スプレッドシートに記録が増えているかで確かめる（同じ記録は二重には書かれません） |
| 保護者画面に何も出ない | お子さんの端末で、設定したあとにまちがえた問題から送られます。両方の端末で設定したかも確かめる |

## 知っておいてほしいこと

- 受け口を作り直す・合言葉を変えたときは、**両方の端末の設定**を入れ直してください。
- 合言葉は、その端末のブラウザに保存されます。お子さんの端末には**送る合言葉だけ**を入れれば、お子さんの端末からは記録を読めません（`READ_SECRET` を入れたとき）。ほかのサービスと同じ合言葉は使わないでください。
- 送られる内容は、まちがえた問題・正解・答えた内容・日付・日ごとの解いた数・お子さんの呼び名（入れたとき）です。本名などは送られません。呼び名は、本名でなくてかまいません。
- 保護者画面には、暗証番号のロックがありません。お子さんの端末でも開けます。
- やめたいときは、保護者画面の「送信をやめる」を押し、Google のスプレッドシートを削除してください。
- この機能は、私の側では実際の Google には接続して試せていません。受け口のプログラムは、Google の部品を模擬したテスト（`node tests/apps-script.js`）と、アプリとの通しのテストで確かめています。最初の設定のあと、実際に 1 問まちがえて、保護者画面に出るかを確かめてください。
