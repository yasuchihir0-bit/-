# 保護者の端末で見る（Google 経由）の設定

お子さんの端末でまちがえた問題と答えた内容を、**お子さんがログインしなくても**、保護者の端末のアプリの「保護者画面」で見られるようにする設定です。
保護者の方が、最初に 1 回だけ設定します（10 分ほど）。**画面の案内にしたがって進めるだけ**で、プログラムを書きかえる必要はありません。

## しくみ

```
お子さんの端末のアプリ ──(送る合言葉)──▶ 保護者の Google の「受け口」 ◀──(見る合言葉)── 保護者の端末のアプリ
```

- 「受け口」は、保護者の Google アカウントのスプレッドシートに作る、小さなプログラム（`Code.gs`）です。記録は、そのスプレッドシートの「まちがい」「学習量」シートにたまります。スプレッドシートを開いて見ることもできます。
- 合言葉は 2 つあり、案内の画面が自動で作ります。**送る合言葉**はお子さんの端末だけに、**見る合言葉**は保護者の端末だけに入ります。お子さんの端末からは、ほかの端末の記録は読めません。
- アプリの提供者は、記録を受け取りません。
- 使うのは、**提供者が置いたアプリ**（https:// で始まるアドレス）です。claude.ai の公開ページでは、この機能は使えません（外への通信が禁止されているため）。
- 全体の仕様は [`docs/SPEC.md`](../../docs/SPEC.md) にあります。

## 1. 保護者の端末で、受け口をつくる

パソコンかタブレットがおすすめです（スマホでもできますが、Google の画面が小さく、操作しにくいです）。

1. アプリを開き、どれかの教科を開いて、いちばん下の **「👪 保護者の方へ」** を押す。
2. **「🛠 受け口をつくる（案内つき）」** を押し、画面の案内どおりに進める。
   1. はじめる前に（合言葉が自動で作られます）
   2. 新しい Google スプレッドシートを開き、**拡張機能 → Apps Script** を開く
   3. 画面の **「コピー」** を押し、Apps Script に貼りつけて保存する（合言葉は入っています）
   4. **デプロイ → 新しいデプロイ → ウェブアプリ**（実行：自分／アクセス：全員）で公開し、承認する
   5. できたアドレス（…/exec）を貼りつけて、**「つながるか確かめる」**
3. 「つながりました」と出たら、この端末（保護者の端末）の設定は終わりです。

とちゅうでやめても、同じ端末で「受け口をつくる」を押すと、続きから再開できます。

**承認のときの警告について**：「Google ではこのアプリを確認していません」と出ます。これは、自分で貼りつけたプログラムには必ず出るものです。**詳細 → （プロジェクト名）に移動 → 許可** で進んでください。このプログラムが触れるのは、そのスプレッドシートだけです（`Code.gs` の先頭の `@OnlyCurrentDoc` の効果です）。

## 2. お子さんの端末を設定する

1. 受け口ができると、保護者の端末に **「お子さんの端末を追加する」** 画面が出ます（あとからは、保護者画面の「📱 お子さんの端末を追加」で出せます）。
2. お子さんの呼び名（例：たろう。本名でなくてかまいません）を入れて、**「設定リンクを作る」** を押す。
3. できたリンクを、お子さんの端末に送ります（LINE・メールなど）。または、お子さんの端末のカメラで QR コードを読みとります。
4. お子さんの端末でリンクを開き、**「この端末に設定する」** を押す。

お子さんが 2 人以上いるときは、1 人ずつ呼び名を変えてリンクを作ります。保護者画面で、お子さんごとに切りかえて見られます。

設定は、その端末で **1 回だけ** です。国語・社会・理科のどれで問題を解いても、まちがえた問題が自動で送られます。

## 3. もう 1 台の保護者の端末で見たいとき

保護者画面の **「👪 保護者の端末を追加」** で、見る専用のリンクができます。その端末で開いて「この端末に設定する」を押します。

## 見かた

- お子さんの端末：問題をまちがえると、数秒後に自動で送られます（通信できないときは、あとでまとめて送ります）。
- 保護者の端末：教科の「👪 保護者の方へ」を開くと、自動で最新の記録を読みこみます。「🔄 記録を更新する」でも読みこめます。

## 受け口を新しくするとき

アプリが新しくなって、保護者画面に「受け口（Code.gs）が古いようです」と出たら、保護者の端末で **「🔧 受け口を新しくする」** を押します。
新しいプログラムをコピーして貼りかえ、**デプロイ → デプロイを管理 → ✏️ 編集 → バージョン「新バージョン」→ デプロイ** で更新します。
アドレスは変わらないので、お子さんの端末の設定はそのままで使えます。

## うまくいかないとき

| 画面の表示 | 原因と対処 |
| --- | --- |
| 合言葉がちがいます／見る合言葉が受け付けられませんでした | 案内の画面でコピーしたプログラムを、そのまま貼りつけたか確かめる。貼りなおしたら、デプロイの更新（新バージョン）も必要 |
| 受け口（Code.gs）が古いようです | 「🔧 受け口を新しくする」で更新する |
| 受け口が受け付けませんでした | アドレスが `/exec` で終わっているか、「アクセスできるユーザー：全員」になっているかを確かめる |
| 返事は確認できませんでした | 送れてはいますが、このブラウザでは返事が読めません。スプレッドシートに記録が増えているかで確かめる（同じ記録は二重には書かれません） |
| このアプリの設定リンクではないようです | リンクが途中で切れているか、ちがうリンクです。保護者の端末で作り直す |
| 保護者画面に何も出ない | 設定したあとにまちがえた問題から送られます。両方の端末で設定したかも確かめる |

## 知っておいてほしいこと

- **設定リンクには合言葉が入っています。** 送る相手の端末にだけ送り、SNS などには載せないでください。リンクを開くと、アドレス欄から合言葉の部分は自動で消えます。
- 知らない人から届いた設定リンクは開かないでください（そのリンクの受け口に、記録が送られてしまいます）。アプリは、Google の受け口（script.google.com）を指すリンクしか受け付けず、設定する前に確認の画面を出します。
- 送られる内容は、まちがえた問題・正解・答えた内容・日付・日ごとの解いた数・お子さんの呼び名です。本名などは送られません。
- 保護者画面には、暗証番号のロックがありません。お子さんの端末でも開けます（お子さんの端末からは、ほかの端末の記録は読めません）。
- やめたいときは、各端末の保護者画面の「アドレスと合言葉を直接入れる…」から「送信をやめる」を押し、Google のスプレッドシートを削除してください。

## 案内を使わずに設定する（参考）

1. Google スプレッドシートを作り、拡張機能 → Apps Script に、このフォルダの `Code.gs` をそのまま貼りつける。
2. `const SECRET = '…';`（送る合言葉）と `const READ_SECRET = '';`（見る合言葉）に、12 文字以上のちがう合言葉を入れて保存する。
3. 上の「1.」の 4 と同じように、ウェブアプリとして公開する。
4. 各端末の保護者画面の「アドレスと合言葉を直接入れる」に、アドレスと合言葉（お子さんの端末には送る合言葉、保護者の端末には見る合言葉）を入れて「保存してためす」を押す。
