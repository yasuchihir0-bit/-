# 受験スケジュール（志望校の出願管理カレンダー）

12月〜2月の **出願開始・出願締切・書類必着・試験・合格発表・入学手続き・納入期限** をまとめて管理する Web アプリです。
志望校をえらぶだけで日程が入り、期限が近づくとお知らせします。インストール不要で、`calendar/index.html` を開くだけで使えます。

## 画面
| 画面 | できること |
| --- | --- |
| 🏠 やること | いちばん近い予定のカウントダウン、期限切れ・1週間以内・その先の予定。手続き系はチェックで「済み」にできる |
| 🗓️ カレンダー | 月のカレンダーに、種類ごとに色分けして表示。日付をタップすると、その日の予定が出る |
| 🏫 志望校 | リストから追加／リストにない学校を自分で入力／日程の編集・削除 |
| ⚙️ 設定 | お知らせのタイミング（14・7・3・2・1日前・当日）、ブラウザ通知、.ics 書き出し、データの書き出し・読みこみ |

## 親の負担を減らす工夫
- **⚠️ 気をつけること** を自動で表示します
  - 2 校の試験日が同じ
  - ある学校の入学手続き（納入）締切が、別の学校の合格発表より前（「本命の結果を待たずに入学金を払うか」を決める必要がある）
- 期限を過ぎてもチェックされていない手続きは、赤く「期限をすぎています」に残ります

## 通知のしくみ
Web アプリは、**閉じているあいだは自分で通知を出せません**（出すには通知を送るサーバーが必要です）。そこで次の 2 つを組み合わせています。

1. **スマホのカレンダーに入れる（おすすめ・アプリを閉じていても届く）**
   - 設定の「📥 カレンダーに入れる（.ics）」で、すべての予定に、えらんだタイミングの通知をつけて書き出します。通知はスマホのカレンダーアプリが出します
   - 終日の予定は「n 日前の朝 9 時」、時刻つきの予定は「n 日前の同じ時刻（当日は 2 時間前）」に通知
   - 家族で共有しているカレンダーに入れれば、夫婦どちらにも届きます
   - まだ入れていないときや、入れたあとに日程・タイミングを変えたときは、ホームに「入れなおしてください」と表示します
2. **アプリを開いたときのお知らせ**：その日にあたる予定を画面に表示し、許可していればブラウザの通知も出します（Android の Chrome でも出るように service worker 経由で出します。service worker は http(s) で開いたときだけ動きます）

## 志望校リスト（`js/schools.js`）
日程は **学校の公式サイト（募集要項）から取る** 方針です。アプリでは学校ごとに次のどちらかを表示します。

| 表示 | 意味 |
| --- | --- |
| ✅ 公式で確認ずみ（確認日） | 公式サイトの募集要項で確かめた日程。公式ページへのリンクつき |
| ⚠️ 公式サイト未確認 | 公式サイトをまだ確かめられていない日程（第三者サイトの情報）。ホームにも警告が出る |

| 学校 | 状態 | 出典 |
| --- | --- | --- |
| 愛知中 | ✅ 確認ずみ（2026/11/8） | [公式「令和9年度 生徒募集要項」](https://www.aichi-h.ed.jp/jh/application-guideline/) |
| 東海中 | ⚠️ 未確認 | 公式サイト（www.tokai-jh.ed.jp）に、この開発環境から接続できなかった |
| 愛知淑徳中 | ⚠️ 未確認 | 公式サイトの URL を特定できなかった |

リストの日程を直したときは、すでに追加している人の画面に「🔄 最新の日程に更新」が出ます（自分で編集した学校は上書きしません）。

学校を足すときは `SCHOOL_PRESETS` に追加します。

```js
{ id: 'xxx', name: '〇〇中学校', area: '地域', year: 2027,
  verified: true, checked: '2026-11-08', source: '〇〇中学校 公式「募集要項」', url: 'https://…',
  events: {
    apply_start: { date: '2027-01-10', time: '10:00', note: '' }, // 出願開始
    apply_end:   { date: '2027-01-20', time: '', note: '' },      // 出願締切
    docs:        { date: '2027-01-22', time: '', note: '' },      // 書類必着
    exam:        { date: '2027-02-06', time: '', note: '' },      // 試験日
    result:      { date: '2027-02-09', time: '', note: '' },      // 合格発表
    proc:        { date: '2027-02-11', time: '', note: '' },      // 入学手続き締切
    pay:         { date: '2027-02-11', time: '', note: '' },      // 納入期限
    brief:       { date: '2027-02-13', time: '', note: '' },      // 入学説明会（欠席で辞退扱いの学校もある）
  } },
```

```bash
node calendar/tests/check.js   # 日付の形式・順番、リマインド、注意表示、.ics のチェック
```

記録はその端末のブラウザ（localStorage）にだけ保存されます。
