# 受験スケジュール（志望校の出願管理カレンダー）

12月〜2月の **出願開始・出願締切・書類必着・試験・合格発表・入学手続き・納入期限** をまとめて管理する Web アプリです。
志望校をえらぶだけで日程が入り、期限が近づくとお知らせします。インストール不要で、`calendar/index.html` を開くだけで使えます。

## 画面
| 画面 | できること |
| --- | --- |
| 🏠 やること | いちばん近い予定のカウントダウン、期限切れ・1週間以内・その先の予定。手続き系はチェックで「済み」にできる |
| 🗓️ カレンダー | 月のカレンダーに、種類ごとに色分けして表示。日付をタップすると、その日の予定が出る |
| 🏫 志望校 | リストから追加／リストにない学校を自分で入力／日程の編集・削除 |
| ⚙️ 設定 | お知らせのタイミング（14・7・3・2・1日前・当日）、ブラウザ通知、.ics 書き出し、データの書き出し・読みこみ |

## 親の負担を減らす工夫
- **⚠️ 気をつけること** を自動で表示します
  - 2 校の試験日が同じ
  - ある学校の入学手続き（納入）締切が、別の学校の合格発表より前（「本命の結果を待たずに入学金を払うか」を決める必要がある）
- 期限を過ぎてもチェックされていない手続きは、赤く「期限をすぎています」に残ります

## claude.ai の Artifact として開く
`python3 calendar/tools/build_artifact.py 出力先.html` で、CSS と JS を 1 枚にまとめた Artifact 用の HTML を作れます。
Artifact では次のちがいがあります（アプリが自動で切りかえます）。
- 通知用のファイル（.ics）は保存できないため、予定ごとに、えらんだカレンダー（Google・Outlook 個人用・Outlook Microsoft 365）の追加リンクを出す
- データの書き出し（JSON）は、Artifact の保存確認を通して保存する
- 確認（削除など）は画面の中のダイアログで聞く（通常版も同じ）

## 連携できるカレンダー
設定の「いつも使うカレンダー」でえらぶと、「やること」の各予定に追加リンクが出ます。

| カレンダー | 方法 |
| --- | --- |
| Google カレンダー | 追加画面のリンク |
| Outlook（個人用 outlook.com・hotmail） | 追加画面のリンク（outlook.live.com） |
| Outlook（仕事・学校の Microsoft 365） | 追加画面のリンク（outlook.office.com） |
| iPhone・Mac のカレンダーなど | .ics ファイル（1件ずつ、またはまとめて。Artifact 版では使えない） |

Yahoo!カレンダーは、予定を追加する公開の URL の形式が確認できなかったため入れていません。

## 通知のしくみ
Web アプリは、**閉じているあいだは自分で通知を出せません**（出すには通知を送るサーバーが必要です）。そこで次の 2 つを組み合わせています。

1. **スマホのカレンダーに入れる（おすすめ・アプリを閉じていても届く）**
   - 設定の「📥 カレンダーに入れる（.ics）」で、すべての予定に、えらんだタイミングの通知をつけて書き出します。通知はスマホのカレンダーアプリが出します
   - 終日の予定は「n 日前の朝 9 時」、時刻つきの予定は「n 日前の同じ時刻（当日は 2 時間前）」に通知
   - 家族で共有しているカレンダーに入れれば、夫婦どちらにも届きます
   - まだ入れていないときや、入れたあとに日程・タイミングを変えたときは、ホームに「入れなおしてください」と表示します
2. **アプリを開いたときのお知らせ**：その日にあたる予定を画面に表示し、許可していればブラウザの通知も出します（Android の Chrome でも出るように service worker 経由で出します。service worker は http(s) で開いたときだけ動きます）

**東海3県（愛知・岐阜・三重）の私立中学 41校・76回**（2027年度入試）を収録しています。日程は公式の資料から取る方針です。

| 県 | 出典 | 内容 |
| --- | --- | --- |
| 愛知（21校） | [愛知県私学協会「令和9年度 私立中学校入試日程一覧」「生徒募集要項」](https://www.aichi.sc/schedule/)（公式） | 出願期間・試験日・合格発表・書類の必着日 |
| 〃 | 愛知中・海陽・愛工大名電の公式の募集要項 | 手続き・納入の締切、時刻、入学説明会など |
| 岐阜（9校） | [岐阜県私立中学高等学校協会「令和9年度 岐阜県私立中学校入試日程」](https://www.sigaku-gifu.or.jp/bosyuyoukou)（公式） | 出願期間・試験日・合格発表（岐阜聖徳は手続き締切も） |
| 三重（11校） | 各校の公式サイト（高田・暁・津田学園） | 県の一覧が無いため学校ごと |

アプリでの表示：

| 表示 | 意味 |
| --- | --- |
| ✅ 公式で確認ずみ（確認日） | すべての日程を公式資料で確かめた |
| ⚠️ 一部が公式未確認／公式サイト未確認 | 公式で確かめられず、第三者サイトの情報を入れた項目がある（その日程にも ⚠️ がつく） |
| 📭 2027年度の日程は未掲載 | 公式サイトにまだ日程が見つからない（三重の6校）。公式ページで確かめて「編集」で入れる |

**未確認・未掲載のもの**（2026年11月8日時点）
- 入学手続き・納入の締切は、私学協会の資料に無いため、多くの学校で空欄です（「未登録」と表示）
- 東海中：公式サイトに、この開発環境から接続できなかったため、手続き締切（2/11 正午）は第三者サイトの情報
- 三重中：第三者サイトの情報
- 四日市メリノール・海星・鈴鹿・セントヨゼフ・皇學館・桜丘（伊賀）：公式サイトに 2027年度の日程が見つからなかった

データは `tools/build_schools.py` で作ります（出典ごとに日程を書き、`python3 calendar/tools/build_schools.py` で `js/schools.js` を出力）。
日程を直すと、すでに追加している人の画面に「🔄 最新の日程に更新」が出ます（自分で編集した学校は上書きしません）。

```bash
node calendar/tests/check.js   # 日付の形式・順番、リマインド、注意表示、.ics のチェック
```

記録はその端末のブラウザ（localStorage）にだけ保存されます。
