# 解き直しノート

採点済みの **解答用紙** と **問題用紙** を写真で取りこみ、まちがえた問題を **教科・単元ごと** にためて、
**忘却曲線** にそって忘れかけたころに解き直すための Web アプリです。
インストールは不要で、ブラウザで `notebook/index.html` を開くだけで使えます（スマホ・タブレット対応、カメラで直接とれます）。

## 使い方

1. **📷 取りこみ**
   1. テストの名前・実施日・教科を入れる
   2. 採点済みの解答用紙と、問題用紙の写真を入れる（何枚でも）
   3. まちがえた問題ごとに「✂ 問題を切り抜く」「✂ 解答を切り抜く」で写真の中を指でなぞってかこみ、
      問題番号・単元・まちがえた理由（ケアレスミス／理解不足／暗記不足／時間切れ・空欄）・正しい答え・ポイントを入れて保存
2. **🏠 ホーム** に、今日解き直す問題の数が出ます。「▶ 解き直しをはじめる」で、
   問題 → ノートに解く → 「答えを見る」 → **○ 解けた／△ あやしい／× 解けない** を自分でつけます（キーボードはスペース・1・2・3）。
3. **📒 ノート** で、教科 → 単元ごとに問題を見られます。単元ごとに「まとめて解く」こともできます。
4. **📊 記録** で、これから 2 週間の予定、まちがえた理由の割合、教科ごとの「にがて単元」ランキングを見られます。

## 復習のしくみ（忘却曲線）

| 結果 | 次に出てくるのは |
| --- | --- |
| 登録したとき | 翌日 |
| ○ 解けた | 次の段階へ：1日 → 3日 → 1週間 → 2週間 → 1か月 → 2か月 → **卒業** |
| △ あやしい | 段階はそのまま、その段階の半分の日数あと |
| × 解けない | 最初（翌日）にもどる |

記憶が 70% くらいまで下がったころに解き直すと考えて、問題の詳細画面に「記憶の目安」と忘却曲線のグラフを出しています。
間隔の日数は ⚙️ 設定で変えられます。予定より前に「今すぐ解く」「まとめて解く」で練習した場合は、× のときだけ予定が最初にもどります。

## AI でまちがいを読み取る（任意）

⚙️ 設定で Anthropic の API キーを入れると、取りこみの 3 番目の画面に「✨ AI でまちがいを読み取る」が出ます。
Claude が解答用紙の ×・減点の設問を見つけ、問題番号・単元・自分の答え・正答・理由の推測と、
**問題用紙・解答用紙それぞれの切り抜き位置** を下書きします。位置や内容は、保存する前に確かめて直してください。

- モデルは `claude-opus-5-5`。SDK（`@anthropic-ai/sdk`）は使うときだけ CDN から読みこみます
- キーはその端末のブラウザ（localStorage）にだけ保存され、写真といっしょに Anthropic の API にだけ送られます。共有の端末には入れないでください
- API の利用料がかかります

## データの保存

問題・写真・設定は、その端末のブラウザ（IndexedDB）にだけ保存されます。
⚙️ 設定の「⬇ 書き出す」で写真ごと JSON に書き出し、別の端末で「⬆ 読みこむ」で移せます。
