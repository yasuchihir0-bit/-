# アプリの置き方（提供する人が 1 回だけ）

アプリを、だれでも開けるアドレス（https://…）に置く手順です。**提供する人が 1 回だけ**行います。
使う家庭は、そのアドレスを開くだけです。家庭ごとにアプリを置く必要はありません。

## 1. 置くファイルを作る

```bash
node tools/build.js site        # dist/ に、置くファイル一式ができる
```

`dist/` には、アプリ本体（`index.html` が教科えらびの画面）と、保護者画面の案内が読む受け口のプログラム（`tools/apps-script/Code.gs`）が入ります。
テストや手順書など、置く必要のないファイルは入りません。

## 2. 置き場所に置く

`dist/` フォルダの中身を、静的なファイルを置けるサービスに置きます。条件は次の 2 つだけです。

- **https://** のアドレスで公開できること（設定リンクや、ブラウザの機能のために必要です）
- 置いたファイルを、そのまま配ってくれること（サーバーで動かすプログラムは不要です）

たとえば Netlify・Cloudflare Pages など、フォルダをアップロードするだけで公開できるサービスがあります（多くは無料のアカウントが必要です）。

### Cloudflare Workers に置く（いまの tokai3.tokai-training.workers.dev）

公開中の `tokai3` は、ファイル一式を **1 つのプログラムに入れて置く方式** にしています。
（静的ファイルとして置く方式は、Claude の作業環境からファイルを送る段階で鍵が上書きされてしまい、置き直せなかったため）

```bash
node tools/build.js worker out/                                              # out/worker.js ができる
npx wrangler@4.156.2 deploy out/worker.js --name tokai3 --compatibility-date 2026-11-16
```

- 置き方が変わっても、アドレス・各ページ・`/kokugo` のような拡張子なしのアドレスは、静的ファイルのときと同じように開けます。
- HTML は開くたびに新しいかを確かめ、ほかのファイルは 5 分間ブラウザに置きます。置き直しは、5 分ほどで全員に行きわたります。
- **Cloudflare の無料プランでは、この方式は 1 日 10 万回までの読みこみの制限**があります（ページを 1 回開くと、数十回の読みこみになります）。1 家庭で使う分には届きませんが、たくさんの人が使うようになったら、有料プランにするか、静的ファイルの方式に戻すことを考えてください。
- 一度この方式で置いたので、Cloudflare の管理画面のドラッグ＆ドロップでは置き直せなくなっている可能性があります。

## 3. 置いたあとに確かめること

1. `https://（アドレス）/` を開くと、国語・社会・理科の選択画面が出る。
2. 教科を開き、いちばん下の「👪 保護者の方へ」に、**「🛠 受け口をつくる（案内つき）」** のボタンが出る。
3. 案内の 3 番目の画面で、プログラムが表示される（`tools/apps-script/Code.gs` を読みこめている）。

## 4. claude.ai の公開ページから移ってくる家庭へ

claude.ai の公開ページで解いた記録は、置き場所のアプリには自動では引きつがれません（ブラウザの保存場所がアドレスごとに分かれているため）。
お子さんの端末で、次のように移してもらいます。**置き場所のアプリで解く前に**行うのが確実です。

1. claude.ai の公開ページの教科えらびの画面で「📦 記録をまとめて移す」→「まとめて書き出す」→「コピーする」
2. 同じ端末で置き場所のアプリを開き、「📦 記録をまとめて移す」→「まとめて読みこむ」に貼りつけ →「中身を確かめる」→「置きかえて読みこむ」

お子さんの端末を受け口に設定してあれば、読みこんだ過去のまちがいも、教科を開いたときに保護者の受け口へ送られます。

## 5. 更新するとき

- 問題やプログラムを直したら、もう一度 `node tools/build.js site` を実行し、`dist/` の中身を置きなおします。
- **アドレス（ドメイン）は変えないでください。** 各家庭の学習の記録・設定は、ブラウザの中にアドレスごとに保存されているため、アドレスが変わると、記録も設定も引きつがれません。
- 受け口（`Code.gs`）の中身を変えたときは、`VERSION`（`Code.gs`）と `MIN_VER`（`js/sheetsync.js`）のルールにしたがってください（[`SPEC.md`](SPEC.md) の「互換性と更新」）。
  版を上げると、古い受け口の家庭には、保護者画面で「新しくしてください」と出ます。家庭は「🔧 受け口を新しくする」の案内で更新できます。

## claude.ai の公開ページ用

claude.ai の公開ページ（アーティファクト）に置くときは、次のように作ります。

```bash
node tools/build.js artifact <出力先>   # ページは start.html。manifest の行などを外したもの
```

claude.ai の公開ページでは、外への通信が禁止されているので、Google 経由の記録のやりとり（受け口）は使えません。
ログインした人どうしの同期（`js/sync.js`）だけが使えます。
